====== Instalaciones

    * Validaciones de los dtos
        pnpm add class-validator class-transformer

    * Para tomar las variables de entorno
        pnpm add dotenv

    * Validaciones de las variables de entorno
        pnpm add zod

    
    * Para poder permitr tomar cookies que vamos a usar para las cuentas de usuario
        pnpm add cookie-parser
        pnpm add -D @types/cookie-parser

====== Encriptar contraseñas bcrypt

    pnpm add bcrypt @types/bcrypt


====== Prisma / Atencion prisma 7 tiene problemas asi que bajamos a prisma 6

    pnpm add -D prisma@6.19.0
    pnpm add @prisma/client@6.19.0
    
    # Iniciamos prisma
        pnpm prisma init
            o
        pnpm exec prisma init

    # Generamos el cliente
        pnpm prisma generate

    # Migramos
        pnpm prisma migrate dev 



================= Docker

    * Creamos el archivo docker-compose.yml y lo configuramos

    * Levantamos docker, al levantarlo y tener configurado el docker-compose.yml nos va a crear la carpeta de postgress, y esa carpeta la tenemos que ignorar en el .gitignore
        docker compose up -d
    
    * Creamos una tabla en tablePlus con los datos que le pusimos
        ports:
        - 5432:5432
        environment:
        - POSTGRES_USER=postgres
        - POSTGRES_PASSWORD=123456
        - POSTGRES_DB=nestNextRealState
